# 第 00 章：阅读指南

> 阅读时间：15 分钟  
> 前置：无  
> 目标：建立一套不会在中途迷路的学习方法

---

## 0.1 先说结论

这个项目有 1 万多行源码，其中仅 `scanner.py` 就有 2000 行。  
**不要从第一行读到最后一行。**

正确的顺序是：

```text
先看它解决什么问题
→ 跑起来
→ 追一条完整请求
→ 再分别读扫描器、Agent、报告、前端
→ 最后改一个小功能
```

这四步比“把每一行都看一遍”有效得多。

## 0.2 你需要什么样的基础

### 必须会

- Python：变量、函数、`if/for`、列表/字典；
- 终端：能 `cd`、运行命令；
- 基本 JSON：知道 `{ "key": "value" }` 是什么。

### 不要求会

- 装饰器、生成器、线程、类型标注——第 04 章会讲；
- LangChain、Agent、工具调用——第 06 章会讲；
- Vue、Vite——第 11 章会讲；
- SSE、SQLite——用到时再讲。

如果你连“函数”和“字典”都不熟，建议先补 2–3 小时 Python 基础，再回来。  
不需要学完整个 Python 教程，能写一个读写文件的脚本就够了。

## 0.3 三种读法

### 读法 1：跟读（推荐）

每章按顺序读，边读边打开对应源码。  
每章末尾都有“自测”，能回答再进入下一章。

适合：

- 完整学习；
- 想以后自己搭 Agent 项目；
- 有时间做练习。

### 读法 2：问题驱动

先跑起来，再带着问题读：

```text
为什么没有 Key 也能生成报告？
为什么 Redis 会出现在技术栈里？
为什么报告里有 path:line？
为什么 Agent 会停下来等我点“允许”？
为什么回答下面有“引用可核对”？
```

每个问题都能定位到章节。

### 读法 3：只读代码地图

时间很少时：

```text
01 项目全貌
03 请求生命周期
15 源码索引
```

先把地图建立起来，再按需要深入。

## 0.5 读代码时只做三件事

### 1. 找入口

每个文件先找：

```text
这个文件被谁调用？
它暴露的函数/类叫什么？
```

例如 `scanner.py` 的入口是 `scan_repository()`，不是 2000 行里的某个正则。

### 2. 找数据结构

先看数据长什么样，再看处理过程：

```text
Snapshot  ← 扫描结果
TechHit   ← 一项技术
Report    ← 最终 JSON
Event     ← SSE 事件
```

看懂结构，流程会简单很多。

### 3. 找边界

问自己：

```text
哪里可能失败？
失败后怎么办？
哪些数据来自模型，哪些来自扫描器？
```

这是理解一个真实项目最重要的能力。

## 0.6 不要做的事

- 不要一开始读完整 `scanner.py`；
- 不要试图背 LangChain 的 API；
- 不要同时打开 10 个文件；
- 不要只看不跑；
- 不要在没有测试的情况下大改；
- 不要把“模型说的话”当成事实。
