## 15.1 术语表

### Agent

能“思考 → 调工具 → 看结果 → 继续思考”的程序。
本项目里由 LangChain/LangGraph 提供循环。

### LLM

大语言模型。
负责解释、归纳、生成文字，不负责精确读文件。

### Tool / 工具

暴露给模型调用的 Python 函数。
模型只生成调用请求，真正执行的是程序。

### Function calling

模型输出“我要调用哪个函数、参数是什么”的机制。

### Prompt

给模型的指令。
本项目分 system prompt 和 task prompt。

### LangChain

模型、工具、消息、中间件的框架。

### LangGraph

Agent 状态图/循环/中断/checkpointer 的底层框架。

### Middleware / 中间件

在模型/工具调用前后自动执行的逻辑。
例如进度、脱敏、限流、重试、HITL。

### HITL

Human-in-the-loop，人机协同。
本项目用于 GitHub 克隆审批。

### SSE

Server-Sent Events，服务器持续推送文本。
运行页事件流、追问流都使用。

### Snapshot

扫描器的完整结果。
文件、语言、清单、技术、模块、入口、依赖图。

### RepoInsight

模型返回的结构化分析结论。
摘要、技术解释、架构、风险、学习路径。

### Manifest

依赖清单，如 `requirements.txt`、`package.json`、`go.mod`。

### Import graph / 模块依赖图

仓库内文件之间的 import 有向图。

### Evidence / 证据

通常是 `path:line` + 原文。
报告尽量让每个结论可回到证据。

### Confidence / 置信度

扫描器对“这项技术确实被使用”的把握：高/中/低。

### AI 推断

代码中没有直接证据，由模型根据上下文推断出的技术。
会标记 `ai_inferred`，并进入 warnings。

### Grounding / 引用核对

检查回答里的文件/行号是否真实存在。

### Semantic grounding / 语义核对

让模型判断“引用行是否支持结论”，可选、按次调用。

### ADR

Architecture Decision Record，架构决策记录。
本项目生成 Markdown 草稿，不编造团队动机。

### 降级

AI 不可用时仍生成规则报告。

### schema_version

报告结构版本。
旧报告通过 `normalize_report()` 补齐。

### Contact Sheet

本项目的设计语言：暗房接触印样、黑底、银白、单一红色。

## 15.5 常见问题

### 没有 Key 为什么还能出报告？

扫描器是确定性的，规则报告不依赖模型。
AI 只是增强解释。

### 为什么报告里有些技术标“AI 推断”？

代码/清单没有直接证据，模型根据上下文推断。
它们会进入 warnings，不能当事实。

### 为什么风险提示数字和风险面板不一致？

报告头用 `report.risks.length`；
风险面板还会补充循环依赖、测试缺失、CI 缺失等结构化发现。

### 为什么技术栈不再默认只显示前 8 项？

产品决策：技术栈是核心内容，保留全量；
用分组、分类、搜索降低阅读成本。

### 为什么没有 Watch 模式？

分钟级 mtime 轮询对写代码没有实际价值；
改完代码用「重新分析」即可。

### 为什么改了前端但页面没变？

没有：

```powershell
cd frontend
npm run build
```

或 8765 还是旧进程。

### 为什么回答没有引用？

模型可能没有引用文件/行号。
UI 会显示“未引用文件/行号”，这本身就是一个信号。

### 为什么“引用可核对”不代表结论正确？

引用核对只检查文件/行号是否存在。
结论是否被代码支持，要看可选的“深度核对”，且仍可能错。

### 为什么测试用 unittest 不用 pytest？

项目要求只装 Python 也能跑；
`unittest` 是标准库。

### 为什么 GitHub 克隆失败？

可能：

- 网络；
- 仓库不存在/私有；
- 审批被拒绝；
- 克隆超时/体积限制；
- git 未安装。

看运行页错误和终端。

## 15.6 最该记住的 10 件事

1. 扫描器负责事实，模型负责解释。
2. 报告不是一段文本，是结构化 JSON。
3. 证据是 `path:line` + 原文。
4. 没有 Key 也能生成规则报告。
5. Agent 是一个“模型 + 工具 + 循环”。
6. HITL 是真的暂停，不是弹窗装饰。
7. 所有工具只读；克隆写盘必须审批。
8. 旧报告要能通过 normalize 继续读。
9. 测试和评测都不调用模型。
10. “可核对”不等于“正确”。
