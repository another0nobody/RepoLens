# Surface: RepoLens type index

## Direction contract

THESIS: The report is a type specimen and an index, not a grid of dashboard cards. Technology names are set at specimen scale; the report's depth is a real axis the reader can move, not another card to open.

OWN-WORLD: Warm paper ground, ink black, one vermilion foundry accent. A self-hosted serif specimen face carries Latin names at large sizes; Chinese headings use a bookish serif; data is typewriter. Flat surfaces, strict baseline, generous negative space; no glass, glow, or gradient text.

STORY: The visitor lands on a giant REPO / LENS specimen, enters a source on a ruled line, then reads the report as an index: choose a technology, move the evidence-depth axis from name to role to modules. The interface teaches the difference between a claim and its evidence by making depth visible.

FIRST VIEWPORT: A narrow left rail with the wordmark and numbered navigation; the main field holds REPO over LENS at specimen scale, a short Chinese instruction, an underline source field, and a compact rule-bound list of capabilities. The primary action is a vermilion “开始分析” at the right end of the source rule.

FORM: Variable-font specimen, catalog challenger 6, seed:84cbf168cc953cb5.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
