# Surface: RepoLens field map

## Direction contract

THESIS: The report is a route through a technical terrain: each section is a leg, each technology a control, and the active evidence is the course line. The surface refuses the dashboard grid; it asks the reader to move through the report rather than scan six equal panels.

OWN-WORLD: Orienteering map materials — cream paper, forest green, contour brown, open yellow, marsh blue, and a course purple reserved for the active route and actions. A self-hosted technical sans carries display and control labels; body is a quiet humanist sans; data is typewriter. Flat colour, thin contour lines, no glass, no glow, no gradient text.

STORY: The visitor sees a terrain (repository), picks a start (source), and follows the course from scan to agent to report. In the report, the left route rail is the leg index; the active leg is purple. Technology rows are control descriptions: code, name, category, modules, role.

FIRST VIEWPORT: A thin map header with legend swatches and navigation; a large FIND THE LINE headline over authored contour lines; a START control holding the source input and a purple “开始分析” action; three course legs below, connected by a purple line. The legend is real product terminology, not decoration.

FORM: Orienteering map, catalog challenger 3, seed:84cbf168cc953cb5.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
